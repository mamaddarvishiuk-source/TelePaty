# 🧠 تله‌پاتی (Telepathy) — بازی مهمانی

A premium Persian party game inspired by Herd Mentality. Built with React + Vite + Tailwind CSS.

## How to Run

```bash
npm install
npm run dev
```

Then open `http://localhost:5173` in your browser.

## How to Play

1. **Setup**: Add 3–10 player names
2. **Each Round**: A question appears — each player answers secretly (pass-and-play)
3. **Reveal**: The most common answer scores 1 point for all who chose it
4. **Ties**: If two answers tie for most common, nobody scores
5. **Keep Going**: Play as many rounds as you want!

## Features

- 🎮 100+ Persian questions (editable)
- 🌙 Dark neon theme with glass effects
- 📱 Fully responsive (mobile-first)
- 🔤 Full RTL / Persian support
- 🏆 Live scoreboard
- 🎉 Confetti celebrations
- 💻 No backend needed — runs entirely in browser

## Tech Stack

- React 18
- Vite 6
- Tailwind CSS 3
- Vazirmatn font (Persian)
